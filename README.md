## 🚀 Getting Started

### Prerequisites

Make sure you have Java Development Kit (JDK) installed on your system.

To check your Java version, run:
```bash
java -version
javac -version
```

### Compiling and Running Programs

1. **Compile**:
   ```bash
   javac helloworld.java
   ```

2. **Run**:
   ```bash
   java helloworld
   ```
